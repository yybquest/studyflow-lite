- 规则清晰，目标明确的用程序做，例如将照片按拍摄日期重命名并放到对应的月份的文件夹。
- 规则不清晰，目标不明确的用模型，训练得到的模型来做，例如在一组图片中找到所有含有树的图片。
- 以上都可以作为agent的工具tool，一个是不会出错的，规则明确的，流程清晰的，可读的程序；一个是可能出错，黑箱的模型，两者都是函数。
- 函数，给输入，按某种规则给出输出。

里其实有个可以改进的地方：第一步我该先确认文件名再读，而不是直接猜路径，这样能省掉一次无用调用。

当你在一件「底层原语」上反复碰壁（get_text、find_tables 都翻车），那通常不是「你用得不够好」，而是你该换抽象层级了——去找那个「专为解决你的真实目标而生的高层工具」，而不是继续和底层 API 死磕。
