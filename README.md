# StudyFlow Lite

这是一个用于记录 Kaggle 5-Day AI Agents Intensive Course 学习笔记的项目仓库。

## 课程目标

学习 AI agent 的核心概念，包括：

- agent 是什么
- prompt 如何变成动作
- 单 agent 与多 agent 的区别
- agent 的基础架构
- 工具调用与输出流程

## Day 1 学习重点

Day 1 的主题是：Introduction to Agents

### 重点内容

- 理解什么是 AI agent
- 区分 chatbot 和 agent
- 认识 agent 的基本循环：input -> reasoning -> action/tool use -> output
- 了解单 agent 与多 agent 的基本架构思路

### 课程要求

- 完成 Day 1a：From Prompt to Action
- 完成 Day 1b：Agent Architectures
- 记录 agent loop
- 记录一个简单的 agent 架构示意
- 形成对 agent 的理解总结
